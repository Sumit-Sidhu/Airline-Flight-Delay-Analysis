# ✈️ Airline Flight Delay Analysis Dashboard
Airline Flight Delay Analysis using Tableau, SQL, and Excel to analyze flight delays, cancellations, airline performance, airport operations, and monthly flight trends through interactive data visualizations.

## 📊 Project Overview

This project focuses on analyzing airline flight operations, delays, and cancellations to identify operational patterns and evaluate airline performance.

Using flight, airline, and airport datasets, this project aims to uncover insights into departure delays, arrival delays, cancellation trends, and airport-level performance through interactive data visualization.

## 🎯 Project Objectives

* Analyze flight delays across different airlines.

* Compare weekday and weekend flight operations.

* Identify monthly flight cancellation trends.

* Evaluate airline-wise departure and arrival delays.

* Analyze state-wise and city-wise flight delays.

* Identify airports with the highest delay frequency.

* Investigate different reasons for flight delays.

* Analyze flight distances and operational performance.

## 🛠️ Tools & Technologies

* Tableau – Interactive dashboard development and data visualization.

* Microsoft Excel – Data exploration and preparation.

* SQL – Data analysis and querying.

* CSV – Dataset management.

## 📂 Dataset Description

The project uses three datasets:

### Dataset

* Airlines: Contains airline information and airline codes.

* Airports: Contains airport names, locations, and IATA codes.

* Flights: Contains flight details, schedules, delays, cancellations, and flight distances.



## 📌 Key Performance Indicators (KPIs)

* Total Number of Flights

* Total Delayed Flights

* Total Cancelled Flights

* Average Departure Delay

* Average Arrival Delay

* On-Time Performance

* Total Flight Distance

## 📈 Business Questions & Analysis

1. How do weekday and weekend flight volumes compare?

2. How many flights were cancelled by JetBlue Airways on the first day of each month?

3. What are the week-wise flight delay statistics?

4. Which states and cities experience the highest flight delays?

5. Which airlines have zero departure and arrival delays for flights covering distances between 2,500 and 3,000 miles?

## 📊 Dashboard Features

* Airline-wise flight performance analysis.

* Monthly flight delay and cancellation trends.

* Weekday vs. weekend flight comparison.

* Airport-wise delay analysis.

* State-wise and city-wise geographical analysis.

* Departure and arrival delay comparison.

* Flight cancellation analysis.

* Flight delay reason analysis.
